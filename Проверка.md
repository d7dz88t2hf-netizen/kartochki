# Карточки 1.1.0 — изменения и проверка

Дата: 16 ноября 2026 года.

## Что было в проекте

Нативная оболочка macOS на Swift/WebKit, оболочка Windows на Go/WebView2 и две независимые копии одного веб-интерфейса. Исходники Windows находились только в `исходники.zip`. Готовые приложения и архивы лежали рядом с исходниками, автоматических регрессионных проверок не было.

## Исправлено

1. **Запись данных.** Основной файл заменяется атомарно; ошибки записи показываются в интерфейсе. Изменения проходят через последовательную очередь с подтверждением от нативного хранилища. Закрытие нативного окна дожидается сохранения.
2. **Восстановление.** Проверяются структура коллекции, настройки и поля прогресса. При повреждении основного файла читается корректная `.bak`. Повреждённый файл сохраняется отдельно при следующей записи. Некорректная запись не заменяет корректную коллекцию.
3. **Конкурентный доступ.** Блокировка файла ограничивает запуск нескольких процессов. API Windows проверяет версию коллекции, чтобы устаревшее окно не затёрло изменения другого окна.
4. **Безопасность Windows API.** Случайный loopback-порт и 256-битный ключ сеанса, проверка Host/Origin/Sec-Fetch-Site, ограничения методов и размера тела, HTTP timeouts. Ответы не разрешают CORS. Токен передаётся интерфейсу через фрагмент URL и затем убирается из адреса; в запросах используется заголовок.
5. **Безопасность WebKit.** Данные не вставляются в JavaScript как исполняемый JSON: используется кодирование Base64 и JSON.parse. Нативные сообщения принимаются только от главного фрейма доверенной страницы. Произвольная навигация блокируется.
6. **Веб-интерфейс.** CSP, экранирование пользовательского текста и идентификаторов, проверка импортируемых объектов. Убраны внешние Google Fonts: программа больше не обращается за ними в сеть.
7. **Импорт.** JSON проверяется целиком; повреждённый JSON не превращается в текстовые карточки. CSV поддерживает кавычки, разделители внутри полей, многострочные поля и CRLF. Ограничение — 32 МБ и 100 000 карточек в коллекции.
8. **Резервные копии.** Экспорт всей коллекции с настройками и прогрессом. Экспорт отдельной колоды сохраняет также дневной журнал новых карточек. Импорт копии сохраняет прогресс и создаёт новые идентификаторы.
9. **Удобство.** Обзор количества колод, карточек и заданий на сегодня; поиск колод по названию и содержимому; доступ к карточкам после первых 300; статус записи и повтор сохранения. Фокус в модальных окнах, управление с клавиатуры, уменьшение анимаций по системной настройке.
10. **Сборка.** Общая папка `web/` для двух платформ. Сборка Mac требует обе архитектуры и проверяет подпись. Windows использует официальный WebView2Loader Microsoft вместо внутреннего экспорта браузерного Runtime. Добавлены воспроизводимые тесты и инструкции.

## Что проверено

- JavaScript: пять групп регрессионных тестов формата данных, миграции старых карточек, прогресса, идентификаторов, отказа на некорректных данных и CSV.
- Go: запись/резервная копия/восстановление, сохранение повреждённого файла, отказ на некорректных настройках, параллельная запись, блокировка второй копии процесса, изоляция API, конфликт версий и ограничения маршрутов. Запуск с `go test -race ./...`.
- Настоящий Chrome с отдельным временным профилем: создание и редактирование карточек, безопасный вывод HTML-текста, обучение и отмена ответа, CSV, некорректный JSON, настройки, скачивание общей копии, повторное открытие, ширина окна 420 px, конфликт двух редакторов и отсутствие внешних запросов.
- Swift: запись, резервная копия, отклонение некорректной записи, восстановление и сохранение повреждённого файла.
- Настоящий WKWebView в тестовом приложении: чтение существующей временной коллекции, Unicode и строка `</script>` в вопросе, нативный мост, запись карточки и немедленный выход с ожидающим подтверждения сохранением. Тестовый WebKit использует непостоянное хранилище; пользовательская коллекция не изменяется.
- Universal macOS binary: x86_64 + arm64, deployment target 11.0; подпись ad hoc и проверка `codesign --verify --strict`.
- Windows: EXE x64 собран перекрёстно из Go; версия ресурса 1.1.0.

## Практические границы проверки

Матрица реальных устройств с macOS 11 и последующими выпусками, Windows 10 и Windows 11 здесь не запускалась. Сборка с нужным deployment target не заменяет такую проверку. Нативная Win32/COM-оболочка и системные диалоги Windows требуют smoke-теста на Windows: запуск с WebView2 и без него, импорт/экспорт, сворачивание, масштабирование DPI и закрытие сразу после изменения.

Для полноценного публичного выпуска остаются Developer ID + notarization Apple и Authenticode для Windows. Учётные данные и сертификаты издателя не предоставлялись, доверенная подпись не создавалась. Не нужно отключать Gatekeeper, SmartScreen или антивирус для работы над исходниками.

Защита рассчитана на посторонние веб-страницы и случайную потерю данных. Приложение не шифрует колоды и не защищает их от вредоносного процесса с правами самого пользователя. `.bak` хранит предыдущую версию, поэтому нужна отдельная внешняя резервная копия.
